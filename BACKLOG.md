# Scene Backlog

How this works: add new scenes under **Requested**, in as much or as little detail
as you have on the go. The scheduled agent picks up anything in **Requested**,
works on it, and either moves it to **In Progress** (leaving open questions for you
inline, tagged `Q:`) or **Done**. Answer any `Q:` lines whenever you get to it — the
agent picks the answer up on its next run and continues.

Don't worry about filling in every field. Missing details just become `Q:` questions
the agent leaves for you.
