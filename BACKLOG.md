# Scene Backlog

This is the index. To request a **new scene**, add a line under "New requests"
below with the project/scene name and whatever detail you have (subject, mood,
layers, atmospheric effects, audio, duration — don't worry about filling in
every field, missing details just become questions). The scheduled agent picks
it up, creates `scenes/<project>/<scene-name>/NOTES.md` for it, and links it
here.

To check on or answer questions about an **existing scene**, open its own
`NOTES.md` directly (linked below) — answer any open questions inline
underneath them, right in that file. Don't edit this index for existing
scenes; the agent maintains the Scenes list below.
